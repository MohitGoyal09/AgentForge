# Explore

Use this skill when you need to quickly orient yourself in a repository.

Workflow:

1. Inspect the top-level layout and entry points.
2. Find the main runtime, config, and tool wiring.
3. Summarize the important files and how they connect.
4. Call out anything surprising, missing, or risky.

Keep the output short, concrete, and focused on helping the user understand the codebase faster.
